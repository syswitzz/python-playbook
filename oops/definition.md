# Methods
Methods are functions defined within a class.

# Attributes
Attributes are variables that belong to an object or class. They store data about the object.

# Properties
Properties are a controlled way to access an attributes. They use methods (get/set). Used for data encapsulation

# Parameters
Parameters are variables passed into a function or method when it is called. They are inputs, not stored data

# OOPS
OOPS in Python is a way of programming where you organize code into objects (using classes) that bundle attributes and methods, making programs more modular, reusable, and easier to manage.

# CLASS
a class is a blueprint or template that defines attributes and methods of object

# OBJECT
an object is an instance of a class that represents a real world entity with its own attributes and method

# INSTANCE
an instance is a specific, created object of a class that occupies memory and has actual values

# EXAMPLE
A class is like a design or plan, and when you create something using that plan, it becomes an instance; that same created thing is called an object when you use it in your program.

# ENCAPSULATION
Encapsulation is an OOP principle where attributes and the methods that operate on it are bundled inside a class, and direct access to the data is restricted, allowing it to be accessed or modified only through controlled methods
This prevents accidental changes to your data and hides the internal details of how your class works.

# INHERITANCE
Inheritance is an OOP principle where one class (child/derived class) acquires the properties and methods of another class (parent/base class). Already existing classes can be extended in such a way that we dont have to rewrite all the code in parent class.

# ABSTRACTION
Abstraction is an OOP principle that hides unnecessary/irrelevant internal details from the user and shows only what is essential, not for security, but because the user doesn’t need to know how things work internally—only what they do.

# POLYMORHISM
Polymorphism is an OOP principle where the same method name can have different behaviors depending on the object. It basically means we can have multiple classes with the same method name.
We can override parents class method allowing polymorphism

Example idea: A start() method—cars start differently from bikes, but the method name stays the same.
Example function: len() function.
